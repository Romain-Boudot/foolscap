Four pillars.

⏱

Programmable timers

Type timer 25m: focus, every 1h x 8: water, at 14:30: standup, or pomodoro 25/5 x 4. They survive restart, fire a chime & toast, and run while the window is hidden.

∑

Inline math & money

Live calculator with named variables, reactive recalc, units (5 km en mi), 30+ currencies refreshed from the ECB, and aggregates over labelled ranges (sum(*_revenue)).

↘

AutoPaste mode

Toggle once, then anything you copy from anywhere lands in the current note automatically. Recording-dot indicator while it's on. No more flipping back & forth.

~

Ephemeral by default

Notes you don't touch for a week disappear at the next launch. Pin the ones that matter. The palette warns you before they go. Knowledge base, this is not.

Slick where it counts.

  • Native Windows 11 acrylic that doesn't dim when the window loses focus.
  • Light, dark, or follow system. Three background modes.
  • Floating title and footer bars that fade in only when you reach for them.
  • Tray icon with quick access to settings, new note, and pinned notes.
  • Custom toast notifications, scrollable, with a soft chime.
  • Variable autocompletion in the editor, smart caret blink, custom scrollbar, the works.

Every action, one keystroke away.

The mouse is allowed but never required. Defaults shown — all remappable in settings.

Summon

  • Show / hide window Alt+A
  • New blank note Ctrl+N
  • Open palette Ctrl+K
  • Clipboard history Ctrl+⇧+V

Navigate

  • Next / prev note Ctrl+→
  • Pin / unpin Ctrl+P
  • Toggle always-on-top Ctrl+⇧+T
  • Settings Ctrl+,

Edit

  • Toggle checkbox Ctrl+⏎
  • Move line Alt+↑↓
  • Clear done tasks Ctrl+⇧+X
  • AutoPaste on / off Ctrl+⇧+P
